# Документация для администраторов

- [Установка и эксплуатация в закрытом контуре](offline-install.md): Docker, установка из wheel-файлов, настройки Oracle, проверка, резервное копирование и обновление.

Рекомендуемый комплект поставки — готовый Docker-образ с Python и всеми
библиотеками. В закрытом контуре образ загружается с носителя; скачивание пакетов
и сборка не нужны. Без Docker поставляется каталог wheel-файлов, но Python и
системные компоненты должны быть установлены отдельно.

Переписывание сервиса на Go ради автономной установки сейчас не требуется.
Оно затронет обработку аварий, API и существующие интеграции. Возможность поставки
одним Go-бинарником нужно отдельно проверять с выбранным Oracle-драйвером и
требованиями целевой ОС. Готовый образ решает текущую задачу поставки зависимостей.
